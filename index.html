How it was calculated

  1. Compute the allowable voltage drop in volts.
  2. Find the minimum cross-sectional area from the voltage-drop formula.
  3. Find the minimum size that can carry the current (tabulated rating ÷ correction factors).
  4. Pick the larger requirement and round up to the next standard cable size.
